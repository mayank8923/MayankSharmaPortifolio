# Personal Portfolio Website

A clean, modern, and fully responsive personal portfolio website designed and developed using pure **HTML5** and **CSS3**[cite: 7, 8]. This site serves as a central hub to introduce my background, highlight core technical skills, and showcase featured engineering projects[cite: 8].

---

## 🌟 Key Features

- **Semantic Architecture:** Structured using standard HTML5 semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`)[cite: 8, 9].
- **Modern Styling & Theming:** Implements CSS custom properties (variables) for a consistent color scheme, clean typography, and balanced spacing[cite: 8, 9].
- **Responsive Layout:** Built with CSS Flexbox and CSS Grid alongside targeted `@media` queries to ensure zero horizontal overflow and readability across mobile, tablet, and desktop screens[cite: 8, 9].
- **Smooth Navigation:** In-page anchor links with smooth scrolling to quickly navigate between sections[cite: 8, 9].
- **Interactive UI:** Micro-interactions, button hover states, and card elevations designed purely in CSS[cite: 9].

---

## 🛠️ Built With

- **HTML5** – Markup and semantic document structure[cite: 7, 8]
- **CSS3** – Layouts (Flexbox & Grid), styling, variables, and responsive design[cite: 7, 8, 9]
